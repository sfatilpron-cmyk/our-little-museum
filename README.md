## Publish free with GitHub Pages
1. Sign in or create a free account at https://github.com/
2. Create a new **public** repository, for example `our-little-museum`.
3. Extract this ZIP and upload all files (`index.html`, `photo1.jpg`, `photo2.png`, `azizul.jpg`, `README.md`) to the repository root.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch **main**, folder **/(root)**, then Save.
7. GitHub will show your website address, usually `https://YOUR-USERNAME.github.io/our-little-museum/`.

Note: a public GitHub Pages site and its uploaded photos can be viewed by anyone with the link. Only share photos you are comfortable making public.
